Signal Radar ranks every pre-token protocol in the sealed snapshot by an implied value derived from the snapshot's own figures: category median MCap/TVL, seven-day growth, and days without a token. Each row ships a six-step farm plan with concrete cost and time; live-token protocols stay in a separate reference view.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input input/snapshot.json
```
